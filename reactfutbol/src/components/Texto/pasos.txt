3. Crear el servicio para conectar con la API
Archivo: ServiceClubs.js.
El servicio separa las peticiones HTTP del código visual de los componentes.
En nuestro ejercicio utilizamos métodos como:
- obtenerClubs() — obtiene los equipos.
- obtenerJugadoresNombre(nombre) — busca jugadores por nombre.
- obtenerJugadoresClub(id) — obtiene jugadores de un equipo.
Ejemplo de la lógica que seguimos:
import axios from 'axios'

export default class ServiceClubs {

    url = 'URL_BASE_DE_LA_API'

    obtenerClubs = async () => {
        let respuesta = await axios.get(this.url + '/rutaEquipos')
        return respuesta.data
    }
}


Es solo un ejemplo de estructura, no el código completo de tu servicio: las URLs deben ser las reales de tu API.
Idea clave para el examen: axios.get() pide datos al servidor, await espera la respuesta y respuesta.data contiene los datos recibidos.

5. Configurar las rutas
Archivo: Router.js.
Importamos BrowserRouter, Routes y Route de react-router-dom.
Las rutas originales se conservaron y añadimos las nuevas páginas.
Ruta	Componente	Función
/	HomeComponent	Inicio
/Apuestas	ApuestasComponent	Listado de apuestas
/insert/apuesta	CreateApuestas	Crear apuesta
/Jugadores	JugadoresComponent	Buscador general
/equipo/:id	EquipoComponent	Tarjeta del equipo
/equipo/:idEquipo/jugadores	JugadoresEquipoComponent	Tabla de jugadores
/equipo/:idEquipo/jugadores/:idJugador	DetalleJugadorComponent	Detalles individuales
El símbolo : indica que esa parte de la URL es una variable.
Por ejemplo, en /equipo/1, el valor de id es 1.
Para obtener ese valor utilizamos useParams() en una función auxiliar y se lo pasamos al componente de clase mediante props.
function EquipoRoute() {
    const { id } = useParams()

    return <EquipoComponent idEquipo={id} />
}


Esto nos permite mantener los componentes de clase que has trabajado en clase, aunque utilicemos un hook en el componente auxiliar.

6. Crear el buscador general de jugadores
Archivo: JugadoresComponent.js.
Este componente permite buscar por nombre o por equipo.
A. Preparar las referencias y el estado
inputNombre = React.createRef()
selectEquipo = React.createRef()

state = {
    jugadores: [],
    equipos: [],
    buscarRealizado: false
}


- createRef() permite leer el valor del input o del desplegable.
- jugadores almacena los resultados.
- equipos almacena las opciones del desplegable.
- buscarRealizado controla cuándo aparece la tabla.
B. Cargar los equipos
Utilizamos componentDidMount() para llamar al servicio cuando aparece el componente.
C. Buscar por nombre
1. Capturar el evento del formulario.
2. Ejecutar event.preventDefault().
3. Leer el nombre con this.inputNombre.current.value.
4. Llamar a obtenerJugadoresNombre(nombre).
5. Guardar los resultados con setState().
D. Buscar por equipo
1. Leer el identificador del desplegable.
2. Comprobar que no esté vacío.
3. Llamar a obtenerJugadoresClub(id).
4. Guardar los resultados en el estado.
5. Mostrar la tabla.
La corrección más importante de este apartado fue utilizar equipo.idEquipo en lugar de equipo.id.
E. Mostrar la tabla
Utilizamos una condición para que no aparezca antes de buscar:
{this.state.buscarRealizado && (
    <table>
        {/* Cabecera y filas */}
    </table>
)}


Y map() para generar una fila por jugador:
{this.state.jugadores.map((jugador, index) => (
    <tr key={jugador.idJugador ?? index}>
        <td>{jugador.nombre}</td>
        <td>{jugador.posicion}</td>
        <td>{jugador.pais}</td>
    </tr>
))}

Así abrimos la página nueva del equipo en vez de reutilizar el buscador general.

9. Crear la tarjeta individual del jugador
Archivo: DetalleJugadorComponent.js.
Esta página muestra la información de un solo jugador.
La tarjeta debe contener:
- Nombre.
- Imagen.
- Posición.
- Fecha de nacimiento.
- País de origen.
- Botón «Volver».
El botón debe regresar a la tabla del mismo equipo:
<NavLink
    to={'/equipo/' + this.props.idEquipo + '/jugadores'}
>
    <button>Volver</button>
</NavLink>


Importante: en el código que hemos preparado, los datos del jugador se pasan mediante state de React Router desde la tabla. Si se actualiza la página de detalles o se entra directamente mediante la URL, esos datos podrían no estar disponibles. Para que sea robusto, lo ideal es obtener el jugador por su identificador desde la API.
También debemos confirmar el nombre exacto de la propiedad de fecha de nacimiento que devuelve tu API. No basta con inventar un nombre de campo: tiene que coincidir con el dato real.

11. Los conceptos que tienes que dominar
Concepto	Para qué sirve
class Component	Crear un componente de clase.
state	Guardar datos que cambian.
setState()	Actualizar los datos y volver a renderizar.
props	Recibir datos desde otro componente.
createRef()	Leer valores de inputs y selects.
componentDidMount()	Cargar datos al montar el componente.
componentDidUpdate()	Reaccionar a cambios en las propiedades.
async / await	Esperar a que termine una petición.
axios.get()	Solicitar datos a la API.
map()	Generar elementos a partir de una lista.
find()	Buscar un elemento concreto en una lista.
NavLink	Navegar entre páginas de React.
useParams()	Leer parámetros de la URL en una función auxiliar.
event.preventDefault()	Evitar la recarga del formulario.
condición && (...)	Mostrar una parte de la interfaz solo cuando se cumple una condición.
Mi consejo para el examen: no memorices todo el código línea por línea. Memoriza el orden y la estructura. Si sabes crear el servicio, cargar los datos, guardarlos en state, recorrerlos con map() y conectar las páginas con Route y NavLink, podrás adaptar este mismo esquema a un ejercicio parecido con clientes, productos, películas, equipos o cualquier otra API.
